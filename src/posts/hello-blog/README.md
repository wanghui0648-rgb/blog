# 你好，世界 👋

这是我的第一篇文章，也是这个博客正式诞生的日子。

## 为什么要写博客？

以前学东西，习惯把笔记丢在本地的 Markdown 文件里，时间久了就再也想不起来翻看。后来发现：**当你知道自己要把一件事写给别人看时，你会理解得更深。** 于是决定搭一个属于自己的小站。

另一个原因很实在 —— 把知识整理成公开的文章，本身就是一份持续更新的作品集。

## 建站三步走

1. **选框架**：用静态站点生成器，内容即代码，Markdown 直接变成网页，不折腾服务器。
2. **搭环境**：安装 Node.js，用 vuepress-theme-hope 的脚手架初始化项目。
3. **写内容 + 部署**：在 `src/` 下写 Markdown，推送到 GitHub，用 GitHub Pages 自动发布。

具体每一步踩了哪些坑，我整理在了 [《用 VuePress theme-hope 搭建个人博客》](/posts/vuepress-setup/) 这篇文章里，欢迎一起交流。

- [ ] 给文章加上评论和阅读量统计
